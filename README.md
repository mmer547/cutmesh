# cutmesh — STL内部＋MRF円筒ゾーン特化のOpenFOAMメッシャー（プロトタイプ）

STL（水密な閉曲面）の**内部**に八分木ベースの多面体メッシュを生成し、OpenFOAMの
`constant/polyMesh` を直接書き出します。回転領域（円筒）は**メッシュ生成の一部として**
切断されるため、円筒壁そのものがメッシュの内部面になります（生成後にセル中心で
ゾーンを選ぶ方式ではありません）。

- 円筒は **寸法指定**（2点＋半径）でも **STL** でも指定可能
- 出力: `cellZones`（回転領域）、`faceZones`（`<name>_interface`：円筒界面、向き付き）、
  STLのsolid名ごとのパッチ、`constant/MRFProperties` の雛形
- 依存: Python 3.9+, numpy, scipy（断面図に matplotlib）。OpenFOAMは不要

> この環境にはOpenFOAMが無いため、`checkMesh` 相当のチェックは自前実装
> （`cutmesh/quality.py`、OpenFOAMと同じ式）で行っています。手元で必ず `checkMesh` を
> 実行して確認してください。

## 使い方

```bash
cd examples/stirred_tank
python3 make_geometry.py              # サンプルSTL（攪拌槽＋4枚パドル翼＋シャフト）
python3 -m cutmesh meshDict.json      # → case/constant/polyMesh, case/constant/MRFProperties
# 断面図も欲しい場合
python3 run.py                        # → slice_z.png, slice_y.png
```

`python3 -m cutmesh <meshDict.json> [-case DIR] [-noCheck]`（プロジェクト直下から実行するか
`PYTHONPATH` に `cutmesh` の親ディレクトリを通してください）

## meshDict.json

| キー | 意味 | 既定値 |
|---|---|---|
| `domain` | 流体領域のSTL（閉曲面、複数solid可。solid名がパッチ名） | 必須 |
| `baseCellSize` | レベル0セルの辺長 [m] | 必須 |
| `surfaceRefinement` | solid名→細分化レベル。`default` で既定値 | `{}` |
| `featureLevel` | 特徴線近傍の細分化レベル（`null`=表面最大レベル） | `null` |
| `featureAngle` | 特徴線抽出の角度 [deg] | 30 |
| `bufferLayers` | レベル遷移ごとのバッファセル数 | 2 |
| `snapTolerance` | 節点スナップ距離（セル辺長比）。スライバー防止 | 0.3 |
| `featureSnapTolerance` | 特徴線（STLの鋭角エッジ・円筒の縁）への節点スナップ距離（セル辺長比） | 0.5 |
| `featureSnapMax` | 実験的: この距離まで特徴線へスナップし、八分木セルが壊れる所だけ取り消す。現状は一部のカットセルが反転するため既定では無効（= `featureSnapTolerance`） | 0.5 |
| `mergeRatio` | 元hex体積比でこれ未満のカットセルを隣接セルに統合 | 0.25 |
| `mergeMaxNonOrtho` | 統合後の非直交角の上限 [deg]。満たす相手が無ければ統合しない | 65 |
| `hangingSnap` | 辺/面に沿って表面へ届かないぶら下がり節点の扱い（`"free"`=表面へ直接投影、`"constrained"`=動かさず φ=0 とみなす） | `"free"` |
| `refinementRegions` | 体積細分化領域 `[{"cylinder": {...}, "level": n}]` | `[]` |
| `featureCaps` | 凸の鋭角部でカット面を特徴線に沿わせる（`"domain"`/`"both"`/`false`。`"both"` は回転ゾーンにも適用） | `"domain"` |
| `patchTypes` | パッチ名→タイプ（`wall`,`patch`,…） | 全て `wall` |
| `rotatingZones` | 回転領域のリスト（下記） | `[]` |
| `case` | 出力先ケースディレクトリ | `.` |
| `addLayers` | 境界層の設定（下記「境界層」）。省略時は層なし | なし |

回転領域:

```json
{ "name": "rotor",
  "cylinder": { "point1": [0,0,0.06], "point2": [0,0,0.14], "radius": 0.07 },
  "surfaceLevel": 2, "volumeLevel": 2, "omega": 31.416, "nonRotatingPatches": [] }
```

STLで与える場合は `"cylinder"` の代わりに `"stl": "rotor.stl", "origin": [...], "axis": [...]`
（`examples/stirred_tank/meshDict_stlRotor.json`）。複数ゾーン可（重ならないこと）。

## アルゴリズム

1. **八分木**: 根グリッド → 表面・特徴線・円筒面・円筒内部の距離基準で細分化 →
   26近傍2:1バランス。ぶら下がり節点は多角形面の頂点として取り込み、面単位で完全適合。
2. **レベルセット**: STLは光線パリティで内外、近傍のみ厳密最近点距離。円筒は解析式。
3. **節点スナップ**: 特徴点・特徴線（`featureSnapTolerance×h` 以内）→ 面（`snapTolerance×h` 以内）の順に節点を移動。
   面上の節点は φ=0 として扱うためスライバーセルが出ない。ぶら下がり節点はまず粗い側の面を
   平面に保つよう辺/面に沿って移動し、届かない（辺/面が表面とほぼ平行な）場合は通常の節点と同じく
   表面へ直接投影する（`hangingSnap: "free"`。粗い側の面がわずかに反る）。投影で八分木セルが壊れる
   所だけ取り消す。`"constrained"` では従来通り動かさず φ=0 とみなす（壁に ≤ 0.3h のくぼみが残る）。
4. **カットセル**（`cutcell.py`）: 多面体を頂点のφで切断。面の分割は**その面の頂点値だけ**
   で決め、交点は辺キーで共有するので隣接セル間で必ず一致（適合性が構成的に保証）。
   カット面＝負側面集合の開いた境界を閉じるループ。
   - 1回目: STLで切断し内側のみ残す → カット面が壁パッチになる
   - 2回目以降: 回転ゾーン面で切断し両側を残す → カット面が**界面の内部面**になる
   - 交点は面へ投影。STLと円筒の交線上の点（シャフト貫通部など）は交互射影で交線へ。
   - **鋭角エッジの保持**（`featureCaps`）: 特徴線がセル面を貫く点を、その面のカット線（弦）に
     挿入する（面キーでキャッシュするので隣接セルと一致）。セル内のカット面は、入口・出口の
     特徴点を結ぶ特徴線（曲線は中点の再帰投影で追従、角点ではスポーク分割）に沿って折り曲げる。
     折り曲げで非凸になったセルは、その面を共有するセルごと従来の面取りカットにやり直す。
     このため凸のエッジは捉えられるが、凹のエッジと円筒縁の外側（常に凹）は面取りのまま。
   - **凹エッジ際の壁接触**（STLのみ）: 凹エッジ（穴の縁や段差の入隅）の隣では、壁面上の節点（φ=0）が
     連なって面に乗る。φ=0 を一律に流体側として補間するとエッジが格子位置次第で 0〜h 面取りされ、
     エッジに沿って凸凹になるため、(a) N と P に挟まれた φ=0 の連続では、φ=0 どうしの辺の内側の点で
     固体／流体を判定し、固体に入る節点でカット線を切る（面単位の判定なので隣接セルと一致。
     表面に届かなかったぶら下がり節点を含む辺は対象外）、(b) 全節点が壁上にある面は、セル側が固体の
     セルからは外す（流体側のセルの壁面になる）。いずれも既存の節点だけを使う。
5. **小セル・非凸セル統合**: 体積比 `mergeRatio` 未満のカット断片と、自分の重心が見えない面を持つ
   （非凸の）セルを、同一ゾーン内の隣接セルへ統合。候補ごとに統合後の形状を評価し、全面の
   ピラミッド体積が正で、隣接セルとの非直交角が最も小さい相手を選ぶ（`mergeMaxNonOrtho` 超は不採用）。
   統合できずに残った小セルのうち、面の三角形分割の四面体が負になる壁際の薄片（曲面の壁と壁上に
   乗った面に挟まれたレンズ状のセルなど）は削除し、その面を隣接セルの壁面にする（面ピラミッドが
   負のものは常に、四面体だけが負のものは露出する面が STL から 0.4h 以内の場合のみ）。
6. **出力**: 上三角順の内部面、パッチごとの境界面、cellZone/faceZone、未使用点の除去。

## 検証結果（examples/stirred_tank、2コアVM、Pure Python）

| 設定 | セル数 | 時間 | 非直交 max / avg | >70° | skew>4 | 体積誤差 |
|---|---|---|---|---|---|---|
| `meshDict.json`（界面L2・内部L2） | 101,982 | 36 s | 63.4 / 4.2 | 0 | 1 | −0.04% |
| `meshDict_coarseRotor.json`（界面L1・内部L0） | 62,500 | 29 s | 56.5 / 5.5 | 0 | 1 | −0.04% |

- セル閉合性 1e-16、セル内の開いた辺 0、負体積 0、面ピラミッド負 0、面順序OK
- 境界面中心とSTLの最大距離 0.71 mm（最小セル1.56 mmの0.46倍。凹の鋭角部の面取り分）
- 円筒界面は粗いセルでも厳密に円筒面上にあるので、**界面のために細分化する必要がない**
  → snappyHexMeshで界面faceZoneを綺麗に取るための細分化に比べ、セル数を抑えられます

## 境界層（`cutmesh/layers.py`）

壁パッチにプリズム層を追加します。メッシュ生成とは独立した後処理で、polyMesh を入力にします。

```bash
# meshDict.json に "addLayers": {...} を書くと生成後に自動で追加
python -m cutmesh meshDict.json
# 既存ケースに追加（ASCII polyMesh。cutmesh 以外のメッシュでも可）
python -m cutmesh.layers CASE [layerDict.json] [-out CASE2] [-noCheck]
```

| キー | 意味 | 既定値 |
|---|---|---|
| `patches` | 層を付けるパッチ名のリスト | type が `wall` の全パッチ |
| `nLayers` | 層数 | 3 |
| `expansionRatio` | 壁から内側への層厚の比 | 1.2 |
| `finalLayerThickness` | 最も内側の層の厚さ（`relativeSizes` なら局所セル寸法比） | 0.3 |
| `relativeSizes` | 厚さを局所セル寸法（壁セルの最大寸法）に対する比で与える | true |
| `minThickness` | 総厚がこれ未満の所は層を付けない | 0.05 |
| `minNormalCos` | 節点法線と面法線の cos がこれ未満（鋭い凸エッジ）の所は層を付けない | 0.25 |
| `maxNonOrtho` | 非直交角 [deg] がこれを超えるセルは不正とみなす（元からある内部面は元の値 + 2° まで許す） | 65 |
| `wallNonOrthMargin` | 元の壁面（層の挿入後は内部面）に、境界面としての角度 + この値 [deg] まで許す。被覆率は上がるが 70° 超の面が出る | なし |
| `maxThicknessSlope` | 壁に沿った単位長さあたりの総厚の変化の上限（層の端を徐々に細らせる） | 0.5 |
| `cornerStretch` | 角の節点を T/cos 動かし、角でも層厚 T を保つ | true |
| `nRings` / `nSmooth` | 内部節点を押し込む範囲（壁からの辺数）とラプラス平滑化の回数 | 6 / 60 |
| `nIter` / `nCollapseIter` | 不正セルの所の厚さを半減する反復回数 / その後に層を止める反復回数 | 8 / 60 |

手順:
1. 壁節点を面積重み付き節点法線に沿って内側へ総厚 T だけ動かす。内部節点は、壁から `nRings` 辺以内を
   ラプラス平滑化（辺長の逆数で重み付け）で追従させる。辺でつながる節点だけに伝わるので薄い固体を
   越えず、壁際の薄いカットセルはほぼ剛体的に動く。
2. 層を付けないパッチ（inlet/outlet など）と faceZone（回転ゾーン界面）上の節点は、その面に沿ってのみ
   動かす。壁節点のうちそれらの縁にあるものも押し込み方向を面内に射影する。界面は円筒のまま保たれ、
   層の側面のうち界面上にあるものは faceZone に加わる。
3. 元の壁位置と押し込んだ位置の間に、壁面ごとに `nLayers` 個のプリズムを挿入する。元の壁面は
   最初の元セルとの内部面になる。
4. 体積・面ピラミッド・非直交角で不正なセルがあれば、関わる壁節点の厚さを半減し、それでも残れば
   0 にする（その節点で層の点が1点に縮退し、層はくさび形のセルで終わる。snappyHexMesh と同じ）。
   厚さは壁に沿って `maxThicknessSlope` で滑らかに変化させる。

ログに、目標の厚さに達した壁節点・薄くなった節点・層なしの節点の割合が出ます。

被覆率を制限しているのは主に、カットセルの重心が壁面の法線上からずれていることです（壁面の法線と
「面中心 − セル重心」のなす角。元のメッシュでは境界面なので checkMesh の対象外）。層を挿入すると
その面が内部面になり、角度がほぼそのまま非直交角になるため、`maxNonOrtho` を超える所で層が止まります。

## エッジ捕捉の計測

`python tools/edge_check.py <meshDict.json> [-case DIR]` は、STLの特徴線と円筒ゾーンの縁に沿って
点を取り、最寄りのメッシュ辺（境界面・界面faceZone）までの距離を最小セル寸法比で表示します。
エッジが捉えられていれば0、面取りされていればセル寸法の数割になります。

## 既知の制約

- STLは水密（閉じた・向きの揃った）である必要あり
- セルより薄い形状（薄翼・バッフル板）は、その厚さ程度まで細分化が必要
- 円筒の縁（リム）や凹の鋭角部はセル寸法程度で面取りされる（界面としては実用上問題小）。
  凸の鋭角部は `featureCaps` と特徴線スナップで多くが捉えられる。凹の鋭角部は、エッジ上へ
  スナップされた節点があれば壁接触の処理で捉えられるが、細かいセルと接する節点はスナップ距離が
  `featureSnapTolerance×(隣接最小セル)` に絞られるため、レベル遷移とエッジが重なる所は面取りが残る
- skew>4 の境界面が少数残る（checkMeshでは "highly skew faces" として1項目失敗扱いになる可能性あり）
- レベル遷移が壁にかかる所のぶら下がり節点は表面へ投影するので壁の凹凸は出ないが、投影で
  八分木セルが壊れる所は取り消され、そこだけ最大0.3×最小セル程度のくぼみが残る
- 統合相手が見つからない小セルはそのまま残る（最小体積が小さくなる）
- Pure Pythonなので遅い。速度比較はC++版で行うべき（下記）

## ロードマップ

1. **境界層**: 自前実装の初版あり（上記）。今後: 層の被覆率の向上（狭い隙間や鋭いエッジでの
   厚さの割り当て）、法線の平滑化、層の品質指標（アスペクト比など）の出力
2. **品質改善**: レベル遷移とカットが重なるセルの追加細分化、薄い（扁平）セルの統合基準
3. **C++化**: 八分木・距離計算（BVH）・カットはセル単位で独立なのでOpenMPで並列化しやすい。
   Pythonで時間の大半を占めるのはレベルセット（距離計算）と面生成
4. **AMI（スライディングメッシュ）への移行**: `<name>_interface` faceZone を `createBaffles` で
   切り離し、cyclicAMIにする手順はsnappyHexMeshのチュートリアルと同じ
