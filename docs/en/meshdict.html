meshDict builder

Fill in the form to generate meshDict.json in the output panel. On narrow screens it appears below the form. Load an STL to get its solid names (patch names) and dimensions, which the form uses for name suggestions and cell count estimates. The output omits default values unless you choose to include them. Files are processed locally in your browser.

You can also drop an STL or meshDict.json file onto this page.

meshDict.json

    Put meshDict.json in the same folder as the STL, then run this command.

    cutmesh meshDict.json
    The fields and defaults come from cutmesh/schema.py. View the JSON Schema.
